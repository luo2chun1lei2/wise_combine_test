# 资源测量报告

## 场景

使用 `doc/examples/many.ct`（7 个无顺序约束的函数）测量不同组合规模下工具的资源消耗。测量命令：

```text
/usr/bin/time -v ./src/out/wise_combine_test doc/examples/many.ct --dry-run \
  --max-flows <n> --report text >/dev/null
```

## 结果

| `--max-flows` | 用户态 CPU（秒） | 系统态 CPU（秒） | 墙钟时间（秒） | 最大常驻内存（KiB） |
| ---: | ---: | ---: | ---: | ---: |
| 10 | 0.00 | 0.00 | 0.00 | 3788 |
| 100 | 0.00 | 0.00 | 0.00 | 4048 |
| 1000 | 0.00 | 0.01 | 0.01 | 5120 |
| 5000 | 0.03 | 0.02 | 0.06 | 8980 |

## 分析

组合流程数量增加时，CPU 时间与最大常驻内存均上升，趋势与 `--max-flows` 规模基本一致。当前示例规模较小，绝对值较低；大规模组合爆炸场景可通过 `--max-flows`、`--max-depth` 等上限控制。
