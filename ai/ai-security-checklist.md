# AI 安全与质量控制检查表

用于 AI 生成代码、模型、adapter、测试或文档时的人工审查。任何一项为“否”都应记录风险、处理方式或回滚计划。

## 输入与提示

- [ ] 提示和输入资料范围是否已记录（模型、版本、提示摘要、输入文件/commit）？
- [ ] 是否避免把 `.agents/auth.json`、密钥、token 或个人数据送入提示？
- [ ] 是否检查提示注入：外部模型/DSL/fixture 文本能否改变工具行为？

## 代码与测试

- [ ] AI 生成代码是否经人工审查、编译和 `make test` 验证？
- [ ] 是否检查不可信代码/harness 的执行隔离（子进程、超时、进程组清理）？
- [ ] 是否检查许可证、第三方依赖和供应商升级影响？
- [ ] 是否记录修改、拒绝、回滚和重新验证结果？

## 发布与维护

- [ ] 模型或供应商不可用时是否有离线复现或替代流程？
- [ ] 资料是否带版本、来源、更新时间和错误状态？
- [ ] 是否有一次“仅凭仓库资料即可定位、修改、测试并回归”的演练记录？
