# 项目提案：函数调用序列与状态机路径测试工具

## 1. 目标

本项目的目标是构建一个基于 C/C++ 的测试工具，用于完成两类测试需求：

### 1.1 函数调用序列测试

- 由使用者描述一系列函数及其语义关系，包括前置条件、资源状态、参数依赖和后置效果。
- 工具据此生成**合法且具有真实语义关系**的调用序列，而不是任意排列组合。
- 例如文件函数中，先生成 `open` 得到句柄，再把句柄传给 `write`，最后 `close` 该句柄，这样的序列才是有意义的组合。
- 生成不同长度的调用序列并运行，检查是否存在问题，例如调用顺序错误、句柄使用不当、资源泄漏等。

### 1.2 状态机路径测试

- 由使用者描述一个 UML 状态图，包括状态、事件和状态转换。
- 工具按照状态图生成不同长度、不同途径的路径。
- 运行这些路径并检查状态切换是否正确。

### 1.3 长期目标

最终形成一个统一工具：输入模型描述，输出并执行测试序列或状态路径，校验运行结果与预期是否一致，并报告发现的偏差或异常。

## 2. 范围

### 2.1 第一版包含的内容

- 提供一种文本形式的 DSL，用于描述函数模型和状态图模型。
- 根据模型生成不同长度的合法调用序列或状态路径。
- 支持常用的覆盖准则，例如状态覆盖、转换覆盖、转换对覆盖、N-switch 覆盖和给定长度内的路径覆盖。
- 运行生成的序列或路径，并与预期状态/预期输出进行比较。

### 2.2 第一版不包含的内容

- 不实现经典的“组合测试（Combinatorial Testing）”，即不处理 t-way 参数取值组合、覆盖数组、PICT/ACTS 一类的参数组合生成。本项目的“组合”指函数调用序列和状态机路径的组合。
- 不自动从代码或需求中推导状态模型；模型由使用者显式描述。
- 暂不提供图形界面，优先使用命令行和文本 DSL。
- 暂不考虑并发、分布式或多线程调用序列。
- 执行层的具体对接方式（工具直接调用被测函数，还是生成序列后交给外部测试框架执行）在后续设计阶段确定。

## 3. 术语

### 3.1 函数调用序列相关

- **函数（Function）/ 操作（Operation）**：被测试的可调用单元。
- **资源（Resource）/ 句柄（Handle）**：由某个函数创建、并在后续函数间传递的对象，例如文件句柄。
- **状态（State）**：资源或系统当前所处的阶段，例如“未打开”“已打开”“已关闭”。
- **前置条件（Precondition）**：函数可以合法执行所需满足的条件。
- **后置条件 / 效果（Postcondition / Effect）**：函数执行后对资源状态或参数产生的变化。
- **数据依赖（Data Dependency）**：一个函数产生的值被后续函数使用，例如 `open` 产生的句柄被 `write` 和 `close` 使用。
- **合法调用序列（Valid Call Sequence）**：每一步都满足前置条件、且数据依赖关系成立的调用序列。
- **序列长度（Sequence Length）**：序列中函数调用的个数。
- **生命周期（Lifecycle）**：资源从创建到释放所经历的状态变化过程。
- **类型状态（Typestate）**：将资源的状态变化编码到模型中的方法。

### 3.2 状态机路径相关

- **状态机（State Machine / FSM）**：由状态、事件和转换组成的模型。
- **状态图（State Diagram）**：状态机的图形化或文本化描述，本项目使用文本 DSL 描述。
- **事件（Event）**：触发状态转换的输入。
- **转换（Transition）**：在事件作用下从一个状态到另一个状态的变化。
- **路径（Path）**：从某个状态出发，经过一系列转换形成的序列。
- **覆盖准则（Coverage Criterion）**：衡量路径集合是否足够充分的标准，例如：
  - 状态覆盖：每个状态至少到达一次。
  - 转换覆盖：每条转换至少执行一次。
  - 转换对覆盖：所有连续两条转换都被覆盖。
  - N-switch 覆盖：所有连续 N 条转换都被覆盖。
  - 路径覆盖：给定长度上限内覆盖所有路径。
- **预期结果 / 预言（Oracle）**：用于判断某次运行是否正确的期望状态或期望输出。

### 3.3 通用

- **模型（Model）**：对函数语义关系或状态机的形式化描述，是工具生成测试序列/路径的输入。
- **测试用例（Test Case）**：一次具体的调用序列或状态路径及其预期结果。
- **被测系统（System Under Test，SUT）**：被运行的函数集合或状态机实现。
