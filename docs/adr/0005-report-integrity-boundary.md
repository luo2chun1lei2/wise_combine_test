# ADR 0005: 报告完整性与重放边界

## 状态

已接受（2026-09-12）。

## 决策

`verify-report` 当前验证报告和运行摘要的 JSON 结构、字段类型及内部计数一致性。
它不声称验证文件来源、内容未被篡改或能够独立重放。报告中的 `seed`、effective
arguments、expected/observed state 和 step 序列属于可追溯元数据，但不是签名。

## 原因

重放需要同时保存规范内容（或稳定引用）、adapter 可执行文件身份、adapter 参数、
工作目录和环境策略；哈希校验还需要冻结规范化编码和算法版本。当前报告格式没有
这些输入，添加一个未经定义的摘要字段会制造不可审计的安全错觉。

## 进入实现条件

先冻结 report schema v2：定义规范/adapter 指纹、参数和环境白名单、规范化字节编码、
哈希算法与版本，再实现 `replay` 命令及篡改失败测试。实现前不得将结构校验描述为
密码学完整性，也不得把 supplied-trigger 回归当作自动覆盖证明。
