# ADR 0004: 高级约束能力边界

## 状态

已接受（2026-09-12）。

## 决策

当前版本只支持状态迁移、函数签名、argument 参数关系和 `before` 全局顺序关系。
`guard`、`mutex`、`parallel`、`count/value`、资源生命周期、多对象交互和负向流程
暂不进入实现；它们在需求矩阵中标为未支持，不得通过未定义字段或 adapter 约定隐式
模拟。

## 原因

这些能力会同时改变 JSON schema、模型校验、候选生成、执行隔离和报告语义。缺少
冻结的输入/输出契约时，实现容易产生“测试脚本能跑但产品语义不明确”的假覆盖，
也无法定义与 Q1–Q6 相同的 clean/mutant 验收标准。

## 后续进入条件

每项能力必须先补充唯一需求编号、schema 示例、非法输入诊断、生成边界、runtime
语义、报告字段、Debug 与 sanitizer 回归，以及 README.md/README.zh.md 同步说明。
完成后再单独提交并更新本 ADR 状态。
